## 链上充币：从别处转币进来怎么操作

链上充币的本质是从另一个平台或钱包向 OKX 转账，和银行转账需要对方账号一样，你需要先拿到 OKX 给你的充值地址。

前置条件是**完成身份认证（KYC）**，只有通过认证的账户才能充币。账户被冻结或受限时，充币功能也可能被限制，具体看页面提示。

App 端有两个入口，效果一样：

1. 打开 OKX App，在首页选 **Deposit crypto**；或者进 **Assets → Deposit → Deposit crypto**。
2. 选择要充的币种。
3. 选择充值网络。
4. 系统自动生成充值详情。在 **Deposit account** 区域，你可以选择把钱充进**资金账户**还是**交易账户**。
5. 复制充值地址，粘贴到对方平台的提现地址栏；或者用对方平台的扫码功能扫 OKX 显示的二维码。
6. 从对方平台发起提币，等待链上确认。

Web 端流程相同：选 Deposit → Crypto → 选币种和网络 → 复制地址 → 从外部钱包或交易所发送。

### 这几条错了钱会丢

- **币种和网络必须完全一致。** 你在 OKX 选的是哪个网络，对方平台提现时就必须选同一个网络。选错网络通常无法找回。
- **充值地址和币种、网络绑定。** 同一个地址不能拿去接收别的币种，也不能换一个网络继续用。
- **OKX 不支持部分网络的充值**，官方举的例子是 BSC 网络上的 USDT。充值页上找不到的代币和网络，就是不支持；强行转入可能丢币。
- **低于最小充值金额不会到账。** 最小金额、所需确认数、合约地址都在充值页面上写明。
- **部分币种除地址外还要填 tag/memo**，例如 XRP，通常是一串数字。漏填同样会丢币。
- **到账时间按币种和网络不同。** 多数在几分钟内确认，但有些网络需要更多链上确认，余额才可用。进度在 **Deposit history** 里查；超时的话，拿交易哈希到对应的区块链浏览器上看状态。

App 端操作：

1. 打开 OKX App。
2. 在 Simple Mode 里选 **Transfer**。

4. 选择你的本地货币。

## 充完不能下单？按这个顺序查五件事

“保证金不足”报错里最常见的成因是钱停在资金账户，账户类型不对，而不是钱没到。按下面的顺序排查，基本能定位到具体哪一步。

1. **钱在资金账户，不在交易账户。** 做一笔内部划转，然后看交易账户里的可用余额。
2. **资金被未成交挂单或现有持仓占用。** 已挂单和持仓的保证金不能拿来开新仓，撤单或平掉不需要的仓位才能释放。
3. **充值还在等待链上确认。** 去 Deposit history 看确认状态，确认完成再做下一步。
4. **这个币种不被当前合约接受为保证金。** 每个合约支持的保证金资产不一样，不支持的话要先换成支持的资产，换之前先看合约的保证金要求。
5. **账户模式不匹配。** 如果你最近改过账户模式，确认交易账户已经正确配置为 X-Perps。部分账户模式会影响不同产品线之间的保证金处理方式。

下单前顺手核对四件事：充值已在链上确认、资金已从资金账户划到交易账户、交易账户可用余额足够覆盖目标保证金、没有资金被挂单或持仓锁住。可用保证金在选中合约、设好杠杆后的下单面板里就能看到；想看完整拆分，去 **Assets → Trading account**，那里显示总权益、占用保证金和可用余额。

## 资金账户划到交易账户：即时、零手续费

这一步是 OKX 账户结构决定的，资金账户负责充值、提现和持币，交易账户负责下单和保证金，两个账户之间的钱不通用。

App 端：**Assets → Transfer**，From 选 Funding account，To 选 Trading account，选币种、填金额，Confirm。

Web 端：**Assets → Transfer**，来源选 Funding，目标选 Trading，输入金额确认。

账户间划转是内部操作，即时到账，不收费。可以只划一部分，也可以全额划，只有划进交易账户的那部分能用于保证金和下单。

## 用什么币入金：保证金资产名单和强平风险

如果入金是专门为了做衍生品，X-Perps 支持多资产保证金，可以直接当抵押品、不必先卖掉的资产包括 **BTC、ETH、SOL、USDC、USDG、DOGE**。也就是说，你账户里本来就有的 BTC 或 ETH 可以直接拿去当保证金，不用先换成稳定币。

代价是抵押品按美元计价。持仓期间，如果作为保证金的资产价格下跌，有效保证金水平跟着下降，强平价会被推近。用 BTC、ETH 这类波动资产做保证金，这部分要提前算进去。

想流程简单一点，用 USDC 起步更省心：它在支持的保证金资产名单里，价值相对美元稳定，主流网络上的支持也比较广。名单会更新，下单时以 X-Perps 合约详情页显示的为准。

## 限额和费用：只有机制，没有统一数字

充值和法币入金都有单笔最小、最大金额，以及日、周、月限额。日限额按滚动 24 小时计算，不是每天午夜重置，而是每笔交易之后往后推 24 小时；周限额同理，按连续 7 天滚动。限额的设定是为了满足当地监管要求。

费用方面，手续费会从入金金额里扣除，实际到账金额少于你支付的金额。具体费率、各档限额、处理时长，不同地区、不同支付方式、不同币种都不一样，以你操作时页面显示的为准，任何写死的数字都可能已经过期。
